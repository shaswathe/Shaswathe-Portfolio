# Shaswathe Portfolio

## Run locally
1. Extract this ZIP file.
2. Open the `shaswathe-portfolio-cursor-ready` folder in VS Code.
3. Install the **Live Server** extension if it is not already installed.
4. Right-click `index.html` and choose **Open with Live Server**.

## Deploy
This is a static HTML/CSS/JavaScript website. You can publish the contents of
`shaswathe-portfolio-cursor-ready` using GitHub Pages, Netlify, or Vercel.

## Important files
- `index.html` — page structure
- `css/style.css` — main styling
- `css/responsive.css` — tablet and mobile layout
- `css/animations.css` — visual animations
- `js/` — projects, menu, reveal, timeline and cursor effects
- `assets/icons/` — technology logos
- `documents/Shaswathe_Resume.pdf` — resume

## Personalise before publishing
- Replace the placeholder image in `assets/images/` with your own portrait if desired.
- Verify the email, LinkedIn and GitHub links in `index.html`.
- Update project links and descriptions in `js/projects.js`.
